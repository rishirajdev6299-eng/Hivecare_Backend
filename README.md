# HiveCare Backend

HiveCare Backend is a RESTful API built using Spring Boot that powers the HiveCare home services booking platform. 
It provides secure user authentication, service management, booking operations, and database integration.

## Features

* User Registration and Login
* RESTful APIs for Services and Bookings
* CRUD Operations for Bookings
* MySQL Database Integration
* Spring Data JPA Repository Layer
* Cross-Origin Resource Sharing (CORS) Support
* Frontend Integration with React

## Tech Stack

* Java
* Spring Boot
* Spring Data JPA
* MySQL
* Maven
* REST APIs

## Project Structure

* Controller Layer
* Service Layer
* Repository Layer
* Entity/Model Layer
* Database Integration
